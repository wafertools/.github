You have probably arrived from a **Discussions** link. Discussions live here because they
are shared across both projects — ask about either one:
**[Discussions →](https://github.com/wafertools/.github/discussions)**

## Looking for the actual tools?

**Want to look at wafer data? → [tsmap](https://github.com/wafertools/tsmap)**

A finished, free, MIT-licensed application: open STDF, ATDF, CSV, JSON or Parquet (plus
`.gz`/`.zip`) and get interactive yield maps, parametric heat maps, findings, charts, lot
galleries and reports — no code, no account, no upload. Native installers for Linux, macOS
and Windows, and a browser build that still parses everything on your own machine.
[Open in the browser](https://wafertools.github.io/tsmap/app/) ·
[Releases](https://github.com/wafertools/tsmap/releases) ·
[Docs](https://wafertools.github.io/tsmap/)

**Building an application? → [wafermap](https://github.com/wafertools/wafermap)**

The rendering and analysis library tsmap is built on — `@wafertools/wafermap` on npm. Pure
ES modules, no runtime dependencies, no server. Reach for it when you need wafer maps
*inside* your own application; otherwise start with tsmap and integrate later.
[Docs](https://wafertools.github.io/wafermap/) ·
[Quick Start](https://wafertools.github.io/wafermap/quickstart/) ·
[npm](https://www.npmjs.com/package/@wafertools/wafermap)
